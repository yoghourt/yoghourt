## Raree Show

[Raree Show](https://raree-show-web.vercel.app) is an AI-native reading companion for long-form literary works. I independently built and deployed it.

The assistant's retrieval context is restricted to the reader's confirmed progress: a SQL visibility filter runs before pgvector reranking, and generation receives only captions already revealed to the reader.

The app conditionally falls back from Gemini to OpenRouter when a failure occurs before streaming begins. Generation requests support explicit cancellation via AbortSignal.
